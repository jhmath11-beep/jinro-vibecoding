성취기준아이디어트랙 · 난이도

GitHub Pages로 배포하기

  1. github.com 가입 → 오른쪽 위 + › New repository, 이름(예: day-balance), Public으로 만들기
  2. Add file › Upload files로 AI가 만든 파일을 올리기. 파일 이름은 반드시 index.html
  3. Settings › Pages → Branch를 main / (root)로 두고 Save
  4. 1~2분 뒤 https://아이디.github.io/day-balance/ 주소가 생김 → QR로 만들어 학생에게 배포
  5. 고칠 때는 같은 이름으로 다시 업로드(덮어쓰기)하면 주소는 그대로

앱스스크립트 실행하기

  1. 구글 시트 › 확장 프로그램 › Apps Script → 기존 코드 지우고 붙여넣기 → 저장(디스크 아이콘)
  2. 처음 실행하면 권한 승인 창이 뜸 → 계정 선택 → "확인되지 않은 앱"이면 고급 › (프로젝트 이름)으로 이동
  3. 폼 제출 때 자동 실행: 왼쪽 트리거(시계) › 트리거 추가 › 이벤트 "양식 제출 시"
  4. 웹앱: 배포 › 새 배포 › 웹 앱. 코드를 고친 뒤엔 배포 관리 › 수정 › 새 버전을 해야 반영
  5. 오류가 나면 빨간 메시지를 통째로 복사해 AI에게 "이 오류 고쳐줘"

진로 실습 안전 수칙

  • 학생 이름·검사 결과는 GitHub에 올리지 않기. GitHub Pages는 공개 주소입니다. 개인정보가 들어가는 과제는 앱스스크립트(학교 계정)로만 만듭니다.
  • 표준화 심리검사 문항을 AI에게 베끼게 하지 않기. 커리어넷·고용24(구 워크넷) 검사 문항과 MBTI 등은 저작권이 있습니다. 문항은 새로 만들고, 공식 검사는 결과값만 옮겨 적어 분석합니다.
  • 결과로 학생을 단정하지 않기. "너는 ○○형이니 ○○ 해야 해" 대신 "이런 경향이 보이네, 어떻게 생각해?"로 쓰도록 프롬프트에 넣습니다.
  • AI가 쓴 진로 정보는 공식 출처로 확인하기. 고교 유형·입시·직업 전망은 바뀌고 AI가 틀리기 쉽습니다. 고입정보포털·커리어넷·고교학점제 누리집과 대조합니다.
  • API 키·비밀번호를 HTML에 넣지 않기. 커리어넷 오픈API처럼 키가 필요한 기능은 앱스스크립트의 스크립트 속성에 보관합니다.
