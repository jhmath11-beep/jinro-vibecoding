진로 시간과 진로 업무에 바로 쓰는 프로그램 9개를 AI와 함께 만들어 봅니다. 오른쪽 화면은 모두 이 실습집의 완성 샘플이고, 눌러서 직접 써 볼 수 있습니다. 과제마다 그 수준이 나오는 시작 프롬프트와 다듬기 프롬프트를 드립니다.

9개를 끝낸 선생님이나, 다른 성취기준으로 바꿔 보고 싶은 모둠에게 줍니다.

성취기준아이디어트랙 · 난이도

GitHub Pages로 배포하기

  1. github.com 가입 → 오른쪽 위 + › New repository, 이름(예: job-worldcup), Public으로 만들기
  2. Add file › Upload files로 AI가 만든 파일을 올리기. 파일 이름은 index.html
  3. Settings › Pages → Branch를 main / (root)로 두고 Save
  4. 1~2분 뒤 https://아이디.github.io/job-worldcup/ 주소가 생김 → QR로 만들어 학생에게
  5. 고칠 때는 같은 이름으로 다시 올리면 주소는 그대로

앱스스크립트 웹앱 만들기

  1. 구글 시트 › 확장 프로그램 › Apps Script → Code.gs에 코드 붙여넣기
  2. 왼쪽 + › HTML로 파일을 만들고 이름을 index로 → 화면 코드 붙여넣기 → 저장
  3. 배포 › 새 배포 › 웹 앱. 실행 사용자와 액세스 범위는 각 Code.gs 맨 위 주석대로
  4. 처음엔 권한 승인 창이 뜸 → "확인되지 않은 앱"이면 고급 › (프로젝트 이름)으로 이동
  5. 코드를 고친 뒤엔 배포 관리 › 수정 › 새 버전을 해야 반영. 오류는 메시지를 통째로 AI에게

진로 실습 안전 수칙

  • 학생 이름·검사 결과는 GitHub에 올리지 않기. GitHub Pages는 공개 주소입니다. 개인정보가 들어가는 과제는 앱스스크립트(학교 계정)로만 만들고, 배포 접근 범위를 꼭 확인합니다.
  • 표준화 심리검사 문항을 AI에게 베끼게 하지 않기. 커리어넷·고용24(구 워크넷) 검사 문항과 MBTI 등은 저작권이 있습니다. 문항은 새로 만들고, 공식 검사는 결과값만 옮겨 적어 분석합니다.
  • 결과로 학생을 단정하지 않기. "너는 ○○형이니 ○○ 해야 해" 대신 "이런 경향이 보여요. 어떻게 생각해요?"로 쓰도록 프롬프트에 넣습니다.
  • 생활기록부는 교사가 쓰는 것. 초안 도우미는 교사의 관찰 기록을 정리할 뿐입니다. 분량·바이트·기재 금지 항목은 해당 학년도 기재요령으로 확인하고, 교사가 최종 검토한 뒤 NEIS에 직접 입력합니다.
  • 생성형 AI·학교 계정 정책 확인하기. 학생 기록을 외부 AI로 보내도 되는지, 무료 AI 서비스가 입력 내용을 어떻게 쓰는지는 교육청·학교 지침과 서비스 약관을 확인합니다. 학교 계정 정책에 따라 웹앱 배포나 외부 호출이 막힐 수도 있습니다.
  • API 키·비밀번호를 HTML에 넣지 않기. 키가 필요한 기능은 앱스스크립트의 스크립트 속성에 보관합니다.
